Questions

Good to know.

Is Magpie free?

Yes. Magpie is free to download and use, with no account and no limit on how much you store.

Where are my files kept?

In a normal folder on your computer, Documents/Magpie, with one subfolder per category. Uninstalling Magpie doesn't touch it, and you can move it anywhere, such as an external drive or a synced OneDrive or iCloud folder, from Settings → Library folder.

Do I need an AI account or API key?

No. Without one, you pick the folder for each item yourself. Auto-sorting is optional: add an Anthropic API key in Settings and Claude files new items for you. That costs about a cent per image, paid directly to Anthropic.

What can I save?

Images (JPG, PNG, GIF, WebP, AVIF, SVG and more), fonts (TTF, OTF, WOFF), PDFs, videos, links, notes, and design source files like .psd, .ai, .fig and .sketch.

macOS says Magpie is damaged or can't be opened.

That's macOS being careful with apps downloaded from the internet. Open Terminal, run xattr -cr "/Applications/Magpie.app", then open Magpie again. You only need to do this once per install.

Windows shows "Windows protected your PC".

Install from the Microsoft Store instead and you won't see it. If you use the .exe installer, click More info → Run anyway.
