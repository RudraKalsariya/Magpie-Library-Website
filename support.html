Support

Help with installing and using Magpie.

Get in touch

Found a bug, or have an idea? Open an issue on GitHub. Say which version you have (it's at the bottom of Settings) and whether you're on Windows or Mac. Please don't post your API key.

Installing

  • Windows: the Microsoft Store version installs in one click and updates itself. With the .exe installer, if a blue "Windows protected your PC" box appears, click More info → Run anyway.
  • Mac: open the .dmg and drag Magpie into Applications. If macOS says Magpie is damaged or can't be opened, open Terminal, run xattr -cr "/Applications/Magpie.app" and open it again.

Updating

Install the newer version over the old one. Your library lives in its own folder in Documents, outside the app, so it and your settings are kept. The Microsoft Store version updates on its own.

Auto-sorting

Auto-sorting is optional. Open Settings, paste an Anthropic API key (get one at platform.claude.com) and switch on Sort new things automatically. It's pay-as-you-go, paid directly to Anthropic: roughly a cent per image, and less with Claude Haiku, which you can pick under Model.

Where your files are

Your library is a normal folder, Documents/Magpie, with one subfolder per category. To keep it somewhere else, such as an external drive or a synced folder, use Settings → Library folder → Change…. Move and rename things inside Magpie rather than in File Explorer or Finder, so its index stays in step with the folders.
